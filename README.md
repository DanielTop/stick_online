# 🎮 Stick MMO - Открытый мир

Многопользовательская онлайн-игра с открытым миром в стиле стик-фигур, с системой прокачки, боссами и двумя силами стихий.

## 🌟 Особенности

- **Система аккаунтов** 👤 - регистрация, вход, сохранение прогресса
- **Никнеймы** - уникальные имена над персонажами
- **PvP режим** ⚔️ - сражайтесь с другими игроками
- **Большой открытый мир** - 15 уникальных зон с разным уровнем сложности
- **Мультиплеер в реальном времени** - встречайте других игроков в мире
- **Два типа сил** - Огонь или Холод, каждая с уникальными способностями
- **Система прокачки** - повышайте уровень и становитесь сильнее
- **15+ боссов** - по одному в каждой зоне
- **Враги** - 100+ врагов разбросаны по миру
- **Адаптивное управление** - поддержка ПК (клавиатура + мышь) и телефонов (сенсорное управление)
- **Стик-арт стиль** - минималистичная графика в стиле стик-фигур

## ⚡ Способности

### 🔥 Огонь
- **Q - Огненный шар** (25 урона, 2 сек кулдаун)
- **E - Взрыв пламени** (40 урона, 4 сек кулдаун)
- **R - Инферно** (80 урона, 8 сек кулдаун)

### ❄️ Холод
- **Q - Ледяной осколок** (20 урона + замедление, 2 сек кулдаун)
- **E - Ледяная тюрьма** (30 урона + контроль, 4 сек кулдаун)
- **R - Метель** (70 урона + массовое замедление, 8 сек кулдаун)

## 🚀 Установка и запуск

### Требования
- Node.js версии 14 или выше
- npm или yarn

### Установка зависимостей

```bash
# Перейдите в папку сервера
cd stick-mmo-game/server

# Установите зависимости
npm install
```

### Запуск игры

**Запуск сервера:**
```bash
cd stick-mmo-game/server
npm start
```

Сервер запустится на `http://localhost:3000`

**Открытие игры:**
Откройте браузер и перейдите по адресу:
```
http://localhost:3000
```

## 🎮 Управление

### ПК (Клавиатура + Мышь)
- **WASD** - Передвижение
- **Мышь** - Поворот персонажа
- **Q** - Первая способность
- **E** - Вторая способность
- **R** - Ультимативная способность
- **ЛКМ** - Быстрая атака (Q)

### Телефон (Сенсорное управление)
- **Левый джойстик** - Передвижение
- **Кнопки справа** - Способности
- **⚔️** - Быстрая атака
- **Q, E, R** - Способности

## 📊 Система прокачки

- Убивайте врагов и боссов для получения опыта
- Каждый уровень увеличивает:
  - Максимальное здоровье (+20 HP)
  - Скорость (+0.2)
- Враги дают 20 опыта
- Боссы дают 200 опыта
