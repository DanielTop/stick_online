# 🌐 Деплой игры - Играйте с друзьями из любой точки мира!

## 🚀 Быстрый старт - ngrok (5 минут)

### Самый простой способ для тестирования:

**1. Установите ngrok:**

**Mac (через Homebrew):**
```bash
brew install ngrok/ngrok/ngrok
```

**Или скачайте с сайта:**
https://ngrok.com/download

**2. Зарегистрируйтесь и получите токен:**
- Перейдите на https://dashboard.ngrok.com/get-started/your-authtoken
- Скопируйте токен

**3. Настройте ngrok:**
```bash
ngrok config add-authtoken ВАШ_ТОКЕН
```

**4. Запустите игру (если еще не запущена):**
```bash
cd /Users/alfa/stick-mmo-game/server
npm start
```

**5. В НОВОМ терминале запустите ngrok:**
```bash
ngrok http 3000
```

**6. Скопируйте URL:**
```
Forwarding  https://xxxx-xxx-xxx.ngrok-free.app -> http://localhost:3000
                    ^^^^^^^^^^^^^^^^^^^^^^^^^
                    Отправьте это другу!
```

✅ **Готово!** Друг может открыть эту ссылку и играть с вами!

### ⚠️ Ограничения ngrok (бесплатная версия):
- URL меняется при каждом перезапуске
- Лимит 40 подключений в минуту
- Показывает предупреждение перед подключением (можно нажать "Visit Site")

## 🌟 Постоянный деплой - Railway.app (БЕСПЛАТНО)

### Railway.app - Рекомендуется!

**Почему Railway:**
- ✅ Бесплатный план (500 часов в месяц)
- ✅ Постоянный URL
- ✅ Автоматические обновления
- ✅ Очень простая настройка

### Инструкция:

**1. Подготовка проекта (УЖЕ СДЕЛАНО):**
- ✅ `.gitignore` создан
- ✅ `package.json` создан
- ✅ Код готов к деплою

**2. Создайте Git репозиторий:**

```bash
cd /Users/alfa/stick-mmo-game

# Инициализируйте git (если еще не сделано)
git init

# Добавьте все файлы
git add .

# Создайте первый коммит
git commit -m "Initial commit - Stick MMO Game"
```

**3. Загрузите на GitHub:**

```bash
# Создайте репозиторий на GitHub.com
# Затем выполните:

git remote add origin https://github.com/ВАШ_USERNAME/stick-mmo-game.git
git branch -M main
git push -u origin main
```

**4. Деплой на Railway:**

1. Перейдите на https://railway.app
2. Нажмите **"Start a New Project"**
3. Выберите **"Deploy from GitHub repo"**
4. Авторизуйтесь через GitHub
5. Выберите ваш репозиторий `stick-mmo-game`
6. Railway автоматически определит Node.js проект
7. Нажмите **"Deploy"**

**5. Получите публичный URL:**

1. После деплоя перейдите в **Settings**
2. Найдите **"Domains"**
3. Нажмите **"Generate Domain"**
4. Скопируйте URL (например: `stick-mmo-game-production.up.railway.app`)

**6. Отправьте ссылку другу:**
```
https://stick-mmo-game-production.up.railway.app
```

✅ **Готово!** Игра работает 24/7!

## 🎨 Альтернатива - Render.com (БЕСПЛАТНО)

### Render - Тоже отличный вариант!

**1. Подготовка (УЖЕ СДЕЛАНО)**

**2. Загрузите на GitHub** (как в инструкции выше)

**3. Деплой на Render:**

1. Перейдите на https://render.com
2. Зарегистрируйтесь
3. Нажмите **"New +"** → **"Web Service"**
4. Подключите GitHub репозиторий
5. Настройте:
   - **Name:** stick-mmo-game
   - **Environment:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** Free

6. Нажмите **"Create Web Service"**

**4. Получите URL:**
```
https://stick-mmo-game.onrender.com
```

⚠️ **Внимание:** Бесплатный план Render засыпает после 15 минут неактивности. Первое подключение может занять 30-60 секунд.

## 🐙 Glitch (Самый простой, но с ограничениями)

### Glitch - Без Git!

**1. Перейдите на https://glitch.com**

**2. Создайте новый проект:**
- Нажмите **"New Project"** → **"glitch-hello-node"**

**3. Загрузите файлы:**
- Удалите все файлы в проекте
- Загрузите содержимое папок `client/` и `server/`
- Скопируйте `package.json` из `server/`

**4. Измените структуру:**
- Файлы из `client/` поместите в корень
- Файлы из `server/` поместите в корень
- Удалите пустые папки

**5. Обновите `package.json`:**
```json
{
  "name": "stick-mmo",
  "version": "1.0.0",
  "main": "server.js",
  "scripts": {
    "start": "node server.js"
  },
  "dependencies": {
    "express": "^4.18.2",
    "socket.io": "^4.6.1"
  }
}
```

**6. Получите URL:**
```
https://your-project-name.glitch.me
```

⚠️ **Ограничения Glitch:**
- Засыпает через 5 минут неактивности
- Перезапускается каждые 12 часов
- Подходит только для тестирования

## 🔧 Устранение проблем

### Railway/Render показывает ошибку:

**Проблема:** Application failed to respond
**Решение:** Проверьте что:
1. `package.json` в корне проекта
2. В `server.js` используется `process.env.PORT`:
   ```javascript
   const PORT = process.env.PORT || 3000;
   ```
3. Все зависимости установлены

### Друг не может подключиться:

**ngrok:**
- Друг должен нажать "Visit Site" на странице предупреждения

**Railway/Render:**
- Подождите 2-3 минуты после деплоя
- Проверьте статус на dashboard
- Откройте URL в своем браузере - должна открыться игра

### WebSocket не работает:

**Решение:** Убедитесь что:
1. URL в клиенте использует `https://` (не `http://`)
2. В консоли браузера (F12) нет ошибок CORS
3. Сервер разрешает WebSocket подключения
