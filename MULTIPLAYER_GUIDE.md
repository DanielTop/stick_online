# 🌐 Руководство по игре с друзьями

## 🎮 Как играть с друзьями

### 📍 Локальная сеть (одна Wi-Fi сеть)

Если вы и ваш друг подключены к одной Wi-Fi сети:

1. **Узнайте свой локальный IP адрес:**

   **На Mac:**
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   ```

   **На Windows:**
   ```bash
   ipconfig
   ```
   Ищите строку "IPv4 Address" - это будет что-то вроде `192.168.1.100`

   **На Linux:**
   ```bash
   hostname -I
   ```

2. **Запустите сервер** (если еще не запущен):
   ```bash
   cd /Users/alfa/stick-mmo-game/server
   npm start
   ```

3. **Отправьте другу ссылку:**
   ```
   http://ВАШ_IP:3000
   ```
   Например: `http://192.168.1.100:3000`

4. **Друг открывает ссылку в браузере** - и вы играете вместе!

---

### 🌍 Через интернет (разные сети)

Если ваш друг НЕ в вашей локальной сети, нужен один из этих способов:

#### **Вариант 1: ngrok (Самый простой)**

1. **Скачайте ngrok:** https://ngrok.com/download

2. **Запустите сервер игры:**
   ```bash
   cd /Users/alfa/stick-mmo-game/server
   npm start
   ```

3. **В новом терминале запустите ngrok:**
   ```bash
   ngrok http 3000
   ```

4. **Скопируйте URL** который показал ngrok:
   ```
   Forwarding  https://xxxx-xxx-xxx-xxx-xxx.ngrok-free.app -> http://localhost:3000
   ```

5. **Отправьте этот URL другу** - он может подключиться из любой точки мира!

   **ВАЖНО:** Бесплатная версия ngrok:
   - URL меняется при каждом запуске
   - Ограничение: 40 подключений/минуту
   - Может показывать предупреждение перед подключением

---

#### **Вариант 2: Проброс портов (Port Forwarding)**

Более стабильный, но требует настройки роутера:

1. **Узнайте свой внешний IP:**
   ```bash
   curl ifconfig.me
   ```
   Или откройте: https://www.whatismyip.com/

2. **Настройте роутер:**
   - Войдите в настройки роутера (обычно `192.168.0.1` или `192.168.1.1`)
   - Найдите "Port Forwarding" или "Проброс портов"
   - Добавьте правило:
     - **Внешний порт:** 3000
     - **Внутренний порт:** 3000
     - **IP адрес:** ваш локальный IP (из шага 1 локальной сети)
     - **Протокол:** TCP

3. **Отправьте другу ссылку:**
   ```
   http://ВАШ_ВНЕШНИЙ_IP:3000
   ```
   Например: `http://87.123.45.67:3000`

   **ВАЖНО:**
   - Ваш внешний IP может меняться (зависит от провайдера)
   - Убедитесь, что порт 3000 открыт в файрволе

---

#### **Вариант 3: Облачный сервер (Самый надежный)**

Разместите игру на сервере:

**Бесплатные варианты:**
- **Heroku** (бесплатный tier с ограничениями)
- **Railway.app** (500 часов/месяц бесплатно)
- **Render** (бесплатный tier)
- **Glitch** (бесплатно, но засыпает без активности)

**Пример для Railway.app:**

1. Создайте аккаунт на https://railway.app
2. Создайте новый проект
3. Подключите GitHub репозиторий или загрузите код
4. Railway автоматически развернет сервер
5. Получите публичный URL для игры

## 🎯 Новые PvP функции

### ⚔️ Боевая система между игроками:

- **Атакуйте других игроков** своими способностями (Q, E, R)

- Видите **здоровье других игроков** над их головами

- **Индикатор подключения** внизу экрана

## 🔧 Изменение порта (если 3000 занят)

Если порт 3000 уже используется:

1. **Откройте файл server/server.js**

2. **Измените строку:**
   ```javascript
   const PORT = process.env.PORT || 3000;
   ```
   на:
   ```javascript
   const PORT = process.env.PORT || 8080;  // любой другой порт
   ```

3. **Откройте файл client/game.js**

4. **Найдите строку:**
   ```javascript
   GAME.socket = io('http://localhost:3000');
   ```
   и измените на:
   ```javascript
   GAME.socket = io('http://localhost:8080');
   ```

5. **Перезапустите сервер**

## 🛠️ Решение проблем

### Друг не может подключиться:

1. **Проверьте файрвол** - убедитесь, что порт 3000 открыт
2. **Проверьте антивирус** - может блокировать входящие подключения
3. **Проверьте, что сервер запущен** - должно быть сообщение "Server: http://localhost:3000"
4. **Попробуйте ngrok** - самый простой способ для быстрого теста

### Лаги в игре:

- **Локальная сеть:** лагов быть не должно
- **Через интернет:** зависит от скорости соединения
- **ngrok:** может добавлять задержку из-за туннелирования

### Игроки не синхронизируются:

1. Откройте консоль браузера (F12)
2. Проверьте наличие ошибок
3. Убедитесь, что версия игры одинаковая у всех игроков
